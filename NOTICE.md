support, or security decisions.

## Modification summary

The derivative work includes substantial changes to branding and local state,
OpenAI Responses compatibility, Codex tool and continuation handling, image,
vision and Web Search flows, native/custom provider routing, proxy and context
controls, desktop management, credential redaction, lifecycle recovery,
Windows packaging, and automated regression coverage. A user-facing comparison
is maintained in the README under **Differences from upstream**.
